# GEMINI Instructions - DrishtiXAI (SIH26038)

## Project Summary
DrishtiXAI is an Explainable AI system for diabetic retinopathy screening.

## Core Rules
1. Never fabricate medical results, DR grades, lesion detections, or confidence scores.
2. Maintain the existing visual design and UX of `frontend/drishtixai.html`.
3. Keep tests passing (`pytest tests/ -v`).
4. Ensure CPU/GPU robustness and PostgreSQL/SQLite database fallback compatibility.
